# Stream Survival — сайт

Статический сайт игры **Stream Survival** («Ты выживаешь. Чат мешает.»).
Без сборки и трекеров: `index.html`, `style.css`, `script.js`, `assets/`.

Публикация: GitHub Pages (ветка `main`, корень). Файл `.nojekyll` отключает Jekyll.

Ассеты: Quaternius, Kenney, Poly Haven, ambientCG (CC0); шрифты Press Start 2P и Pixelify Sans (OFL).
